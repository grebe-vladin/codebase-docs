# Security

The plugin runs locally. It reads your repositories, writes into the documentation folder you choose, and calls two external services only when you enable them: the npm registry (dependency report) and Google's Gemini API (optional Pro diagrams, key from `GEMINI_API_KEY`). Screenshots use your own Chrome session; the plugin never types credentials.

Report a vulnerability privately to the maintainer via GitHub (security advisory on the repository) rather than in a public issue.
