Flow 1 — Create and fulfil an order

From the operator clicking “Save & send” to the result showing up in the list

Operator
Fills the order form, clicks  Save & send
Sees status  done + output
Web app
Validates form (zod), POST /orders
Polls GET /orders/:id every 3 s
API
OrdersService.create() saves order, enqueues job
Returns order with latest job
Worker
OrderFulfilmentProcessor calls payment API, stores result
Database
order_jobs.status = done

Failure path: if the payment API errors 3 times, the job is marked failed and the list shows a retry button (see §4.1).
